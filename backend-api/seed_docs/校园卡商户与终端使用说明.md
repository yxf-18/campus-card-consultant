# 校园卡商户与终端使用说明

> 演示资料，不作为学校正式制度依据。

校园卡能在哪些地方刷、刷不上该找谁，取决于商户类型和终端归属。很多被判断为卡片损坏的情况，其实是终端离线、商户未开通或操作方式不对。

## 商户的类型
- 校内自营场景，例如食堂、宿舍洗衣、浴室、场馆，通常由学校统一管理。
- 引入的第三方商户，例如超市、咖啡店、打印店，通过签约接入校园卡支付。
- 自助设备，例如售货机、充电桩、复印机，终端由设备方维护。
- 线上缴费场景，通过校园卡账户在应用内完成支付。

## 终端的类型
- 联机终端，需要网络实时向后台请求扣款。
- 脱机终端，先记录交易再批量上传，可能出现延迟入账。
- 扫码终端，读取校园码完成支付，依赖网络和二维码有效期。
- 自助终端，支持查询、充值、补打凭条等操作。

## 正确使用方式
- 刷卡时把卡片贴近读卡区并停留片刻，不要快速划过。
- 扫码时调高屏幕亮度，避免二维码被遮挡或反光。
- 一次交易完成后再进行下一次，连续快速刷卡容易产生重复请求。
- 交易完成后看一眼终端显示，确认金额与状态再离开。
- 需要凭条时当场打印，事后补打可能受终端功能限制。

## 终端报错的分类判断
- 提示余额不足：属于账户余额问题，充值后再试。
- 提示无效卡或读卡失败：先换终端，仍失败则考虑卡片损坏。
- 提示网络异常或连接超时：属于终端侧问题，可稍后重试或用其他方式支付。
- 提示商户未开通：该终端可能未接入该支付方式，与卡片无关。
- 提示权限不足：多见于门禁、图书馆等场景，属于权限配置问题。

## 商户侧问题与卡侧问题怎么区分
- 同一张卡在其他终端正常，只在某一台失败，多为终端问题。
- 同一台终端其他人能刷、自己不能刷，多为卡片或账户问题。
- 换个时间段再试恢复正常，多为网络或系统繁忙。
- 商户说系统坏了时，可请其确认是否已报修，不要反复刷卡。
- 商户刚更换设备或重装系统后，新终端可能需要重新配置。
- 终端长期贴有故障提示的，直接换一台更省时间。

## 商户签约与结算的关系
并不是校内所有商户都必须支持校园卡，能否刷卡取决于是否完成签约和终端部署。
- 商户是否受理校园卡，以签约结果和终端配置为准。
- 结算周期由商户与学校约定，学生侧通常感知不到。
- 商户更换终端或系统升级期间，可能短暂无法刷卡。
- 遇到商户拒收校园卡，可先确认其是否属于签约范围。
- 具体受理商户与结算安排以学校正式通知为准。

## 消费凭证与反馈
- 保留终端打印的凭条，上面通常有终端编号和时间。
- 没有凭条时，记录消费时间、地点和金额。
- 对扣款有疑问，先向商户确认交易是否成功，再联系卡务方核查。
- 反映问题时报终端编号比报商户名称更准确。
- 具体商户名单和受理范围以学校正式通知为准。
