# 毕业离校与卡片注销说明

> 演示资料，不作为学校正式制度依据。

毕业生离校前应处理校园卡余额、欠费和卡片注销等事项，避免影响离校手续。

## 离校前检查
- 查询校园卡余额和最近交易，确认没有未结清消费。
- 检查是否存在欠费、冻结或异常交易待处理。
- 确认图书馆、宿舍、门禁等关联权限的注销要求。

## 余额处理
- 余额退还方式、时间和所需材料以学校正式通知为准。
- 部分学校支持线上申请退余额，部分需要到服务窗口办理。
- 退余额前请保留申请凭证和银行卡信息核对结果。

## 卡片注销
- 按学校离校流程提交注销申请。
- 注销后校园卡、校园码及相关权限通常停止使用。
- 如需保留纪念，可咨询学校是否允许注销后留卡，但卡片功能会失效。

## 注意事项
- 不要将校园卡转卖给他人。
- 注销前解绑不必要的自动扣费或关联服务。
- 具体办理地点和截止时间以学校离校通知为准。
