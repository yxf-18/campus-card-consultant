# 校园卡优惠资格变更说明

> 演示资料，不作为学校正式制度依据。

优惠资格决定校园卡在食堂、场馆、交通等场景能否享受折扣。它不是一成不变的，学籍状态、人员类别、认定结果发生变化时，资格也会随之调整。

## 优惠资格是什么
- 它是账户上的一种身份标记，终端在扣款时据此计算优惠。
- 资格通常与人员类别挂钩，例如学生、教职工、临时人员可能适用不同规则。
- 资格生效后不需要每次出示证明，系统按账户自动判断。
- 具体优惠范围和折扣标准以学校正式通知为准。

## 哪些情况会触发变更
- 新生入学完成学籍注册，资格由无到有。
- 升学、转专业、休学、复学等学籍状态变化。
- 身份类别改变，例如学生转为教职工，或人员类别重新认定。
- 毕业、退学、离职等原因导致资格终止。
- 家庭经济困难认定等专项资格按年度重新评定。

## 变更的生效时间
- 资格变更一般按批次处理，不是提交后立即生效。
- 学籍数据同步到卡务系统需要时间，刚办完手续当天可能仍按旧资格计费。
- 生效时间可能按自然月、学期或认定批次划分，具体以学校正式通知为准。
- 变更生效前的消费通常不追溯调整，除非学校另有规定。
- 遇到跨批次的情况，可向业务部门确认自己落在哪一批。

## 怎么申请或申诉
- 先确认变更原因属于哪类业务，学籍问题找教务或学籍部门，认定问题找对应评审部门。
- 由业务部门确认资格状态后，再推动数据同步到卡务系统。
- 卡务窗口一般不能直接修改资格，只能协助核实与转办。
- 申诉时提供学号、姓名、涉及的时间段和具体场景。
- 涉及认定的，准备好相关证明材料，按通知要求提交。

## 变更后没有生效怎么办
- 先在应用内查看当前的资格状态，确认系统里到底是什么标记。
- 核对业务部门是否已完成审批，审批未完成时同步不会发生。
- 确认生效时间是否已到，批次处理存在时间差。
- 超过合理时间仍未变化，通过正式渠道提交核查，说明已完成的审批环节。
- 过渡期内可保留消费凭证，便于后续申请处理。

## 资格与场景的对应关系
同一种资格在不同场景的适用范围可能不同，食堂、场馆、交通往往各有一套规则。
- 某项场景享受优惠，不代表所有场景都享受。
- 部分场景按身份类别定价，与卡内余额无关。
- 跨校区使用时，资格是否通用以学校正式通知为准。
- 资格页面显示的是账户标记，不一定等于该场景的实际折扣。
- 遇到场景与资格不匹配，先向该场景的管理方确认。

## 注意事项
- 不要通过非正式渠道请求改资格，这类操作风险高且通常无效。
- 资格仅限本人使用，转借卡片享受优惠可能被认定为违规。
- 资格终止后继续使用旧标记消费，可能被要求补缴差额。
- 发现资格标记明显错误时尽早反馈，时间越久核查越困难。
