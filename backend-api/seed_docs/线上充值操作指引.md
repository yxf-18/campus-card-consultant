# 线上充值操作指引

> 演示资料，不作为学校正式制度依据。

线上充值可减少排队时间，但具体入口、限额和到账时间以学校官方渠道为准。

## 操作步骤
1. 从学校官网、官方公众号或校园卡应用进入充值页面。
2. 核对当前登录账号与校园卡号，确认是本人账户。
3. 选择充值金额，注意页面提示的单笔和单日限额。
4. 完成支付后返回校园卡页面查询余额和充值记录。
5. 若余额未及时更新，可稍后刷新，避免重复支付。

## 充值异常
- 已扣款但余额未增加：保留支付订单号、支付时间和金额，通过学校正式客服渠道反馈。
- 重复扣款：不要再次充值，提交订单截图并申请核查。
- 充值金额充错账户：立即联系卡务中心，说明订单信息和充值时间。

## 安全提醒
- 只使用学校公布的官方充值入口。
- 不向他人提供支付密码、短信验证码或银行卡完整信息。
- 对“代充优惠”“低价充值”等非官方渠道保持警惕。
