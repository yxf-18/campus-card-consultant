# 学生优惠资格认定说明

> 演示资料，不作为学校正式制度依据。

学校可能面向在校学生提供校园卡消费优惠，具体对象、比例和有效期以最新正式文件为准。

## 资格范围
- 通常以具有正式学籍的在校学生为主，具体范围由学校认定。
- 交换生、进修人员、毕业生等群体的适用情况可能不同。
- 已毕业或学籍状态异常时，优惠资格可能自动失效。

## 认定材料
- 本人有效学生证或校园卡。
- 学校要求的身份证明或学籍证明。
- 如委托他人办理，还需按学校要求提供授权材料。

## 查询与申诉
- 通过学校官网、校园卡服务中心或官方应用查询最新优惠政策和认定结果。
- 对资格认定有异议时，按学校公布的申诉渠道提交材料。
- 本咨询工具只提供政策查询指引，不能直接认定资格或修改优惠状态。
