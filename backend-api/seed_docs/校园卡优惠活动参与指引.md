# 校园卡优惠活动参与指引

> 演示资料，不作为学校正式制度依据。

学校或合作商户可能不定期开展校园卡优惠活动，参与前请先确认活动规则。

## 参与前确认
- 活动主办方是否为学校或学校授权单位。
- 活动是否限定校园卡支付、指定商户或指定时间段。
- 优惠是否限量、是否需要提前报名或领取资格。
- 活动规则中的有效期、退款规则和名额限制。

## 参与方式
1. 通过学校官网、官方公众号或校园卡应用查看活动入口。
2. 按活动要求完成报名或身份验证。
3. 在指定商户使用校园卡或校园码支付。
4. 支付后核对优惠金额和交易流水。

## 风险提示
- 不点击来源不明的“校园卡优惠”链接。
- 不向陌生人提供校园卡密码、验证码或完整卡号。
- 对要求先转账、先交押金的活动保持警惕。
- 活动规则以主办方最新公告为准，本工具不承诺优惠一定可用。
