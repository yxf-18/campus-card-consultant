# 校园卡临时优惠活动规则

> 演示资料，不作为学校正式制度依据。

临时优惠活动通常是限时、限额、限场景的，规则细节决定了能不能享受、能享受多少。参与前先看清条件，比消费后再申诉更省事。

## 活动的常见形式
- 满减：单笔消费达到门槛后减免固定金额。
- 折扣：按比例减免，通常设有优惠上限。
- 立减：支付时直接扣减，不需要额外操作。
- 返券或返现：消费完成后按规则返还到账户或券包。
- 特定时段优惠：仅在公布的时段内有效。

## 参与条件
- 需要使用本人校园卡或校园码支付，代刷通常不计入。
- 消费场景需在活动商户名单内，名单外消费不享受优惠。
- 单笔金额需达到活动门槛，刻意拆单可能不被认可。
- 部分活动需要提前报名或领取资格，未报名不生效。
- 名额有限时按先到先得处理，用完即止。

## 优惠怎么算
- 优惠金额一般在支付时直接抵扣，明细中会单独列示。
- 设有上限的活动，减免不会超过公布的最高额度。
- 与其他优惠是否可叠加，取决于活动规则，默认不叠加。
- 退款时优惠部分通常按原路径扣回，实付金额才是退款依据。
- 具体门槛、比例和上限均为示例性质，以学校正式通知为准。

## 没有享受到优惠怎么办
- 先确认消费时间是否在活动有效期内。
- 核对商户是否在名单内，终端是否已完成活动配置。
- 确认支付方式是否符合要求，例如是否误用了其他支付渠道。
- 检查是否已达到名额上限或超出单笔门槛。
- 保留消费凭证，通过正式渠道反馈，说明时间、商户和金额。

## 活动的变更与终止
- 活动可能因名额用尽、商户调整或系统原因提前结束。
- 规则调整一般会通过官方渠道公告，以最新公告为准。
- 已完成的交易按交易时的规则处理，一般不受后续调整影响。
- 对活动规则有疑问，应在消费前确认，而不是消费后推定。
- 活动是否延续、是否顺延，以学校正式通知为准。

## 参与前先确认四件事
把下面几点确认清楚，基本可以避免大部分优惠争议。
- 活动起止时间，注意是否按自然日划分。
- 适用商户与终端，名单可能定期更新。
- 支付方式要求，扫码与刷卡是否都计入。
- 优惠上限与名额，是否已经被用完。
- 退款与撤销规则，已享优惠是否会被收回。

## 常见误会
不少争议来自对规则的理解偏差，提前说明可以减少误会。
- 满减通常按单笔计算，分多次支付一般不能累加。
- 名额用完即止，页面显示参与成功才代表占位。
- 活动价与会员价通常不叠加。
- 活动结束后的消费按原价结算，不再补差。

## 注意事项
- 不要为了凑门槛而超额消费，优惠不等于必需。
- 不参与需要提供密码、验证码或转账的所谓优惠活动。
- 不轻信非官方渠道发布的活动信息，避免钓鱼链接。
- 遇到要求私下退款的，先向学校正式渠道核实。
