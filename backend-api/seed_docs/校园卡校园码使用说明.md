# 校园卡校园码使用说明

> 演示资料，不作为学校正式制度依据。

校园码是校园卡的电子凭证，可在支持校园码的食堂、超市和校内服务点出示使用。

## 使用步骤
1. 打开学校官方校园卡应用或小程序。
2. 确认当前登录账号为本人，页面显示姓名与卡号后四位。
3. 在消费终端出示校园码，等待终端提示交易成功。
4. 交易完成后核对金额，再离开终端。

## 安全提醒
- 校园码具有支付属性，不要截图转发给他人。
- 校园码页面长时间停留后可能自动失效，重新进入即可刷新。
- 手机丢失时，请优先通过学校正式渠道冻结校园码，并办理挂失。
- 校园码无法使用时，可尝试刷新页面或更换网络；仍无法使用请前往卡务中心核实卡片状态。

## 常见问题
- 校园码显示“已过期”：退出页面后重新进入，或检查手机时间是否准确。
- 校园码提示“卡片状态异常”：可能存在挂失、冻结或余额不足，请查询账户状态或咨询卡务中心。
