# 校园卡挂失与解挂说明

> 演示资料，不作为学校正式制度依据。

校园卡遗失后应尽快挂失，降低被他人使用的风险。

## 挂失
- 通过学校官方校园卡应用、服务电话或卡务中心窗口办理挂失。
- 挂失时需提供学号、姓名等身份信息，按渠道要求完成核验。
- 挂失成功后，原卡在多数消费场景会被限制使用。
- 若卡片随后找回，可咨询是否支持解挂；部分场景补办后原卡即作废。

## 解挂
- 解挂通常需要本人身份核验，具体是否支持以学校规则为准。
- 解挂前请确认卡片仍在有效期内且未被补办替换。
- 解挂后建议先查询余额和最近交易，确认没有异常消费。

## 补办衔接
- 确认无法找回后，按补办流程提交申请。
- 补办期间可使用校园码或临时凭证，具体以学校通知为准。
- 补办新卡后，原卡余额和交易记录是否自动转移以学校系统规则为准。
