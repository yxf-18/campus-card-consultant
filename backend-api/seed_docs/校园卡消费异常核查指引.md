# 校园卡消费异常核查指引

> 演示资料，不作为学校正式制度依据。

发现重复扣款、金额不符或终端故障时，应按学校流程提交核查。

## 需要保留的信息
- 消费时间，尽量精确到分钟。
- 消费地点和商户名称。
- 终端编号或窗口号，如终端屏幕或小票上有显示。
- 交易金额和支付方式。
- 校园卡卡号后四位或校园码交易流水号。
- 如有可能，保留小票、订单截图或终端提示照片。

## 核查流程
1. 先在校园卡应用或自助终端查询交易流水，确认是否重复记账。
2. 若确属异常，通过学校公布的客服渠道提交核查申请。
3. 按工作人员要求补充材料，保持联系方式畅通。
4. 核查期间不要重复刷卡或重复支付。

## 处理原则
- 系统不会仅凭口头描述直接退款或改账。
- 涉及金额争议时，以学校后台交易记录和商户对账结果为准。
- 对处理结果有异议的，可按学校公布的申诉渠道继续反馈。
