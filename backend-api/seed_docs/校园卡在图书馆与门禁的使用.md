# 校园卡在图书馆与门禁的使用

> 演示资料，不作为学校正式制度依据。

校园卡在图书馆和门禁场景承担身份核验功能，与消费功能共用同一账户，但权限是分开管理的。能消费不代表能进馆，能进馆也不代表能借书，遇到问题时先分清是哪一层权限没有生效。

## 图书馆里的用途
- 入馆闸机刷卡或刷校园码，系统核验身份后放行。
- 借阅图书时作为借书证使用，借阅额度与期限按图书馆规则执行。
- 使用自助借还机、座位预约机、打印复印设备时可能需要再次验证。
- 部分研讨间、电子阅览区需要额外申请权限，开通后才能刷开。

## 门禁场景的用途
- 宿舍楼、教学楼、实验楼、办公楼等区域的门禁，按人员类别分配通行范围。
- 通行权限通常与学籍状态、所属院系、住宿信息关联。
- 权限变更需要业务部门提交，卡务方无法直接为学生开放区域。
- 访客、临时人员一般使用临时凭证，不等同于正式校园卡。

## 刷卡没有反应怎么办
- 先确认卡片是否贴近读卡区，多数终端需要停留片刻而不是快速划过。
- 检查卡片是否弯折、磨损、贴了金属贴纸，或与手机磁吸长期放在一起。
- 换一台终端再试，排除单台设备故障的可能。
- 用校园码替代刷卡，确认是卡片问题还是权限问题。
- 若校园码能进、实体卡不能进，多为卡片损坏，按补办流程处理。
- 读卡区有污渍或积水时，读卡成功率会下降，可请工作人员清洁。
- 同一张卡在多台终端都失败，基本可以判定为卡片本身的问题。

## 提示无权限怎么办
- 核对提示文字，区分无效卡、权限不足、账户异常等不同含义。
- 权限不足通常与身份状态有关，例如学籍变动、住宿调整、实验室授权未同步。
- 联系对应业务部门确认权限是否已开通，再等待系统同步。
- 权限同步需要时间，刚办完手续就刷卡失败属于常见情况，可稍后再试。
- 具体开通条件与生效时间以学校正式通知为准。

## 校园码与实体卡怎么配合
校园码是实体卡的补充，多数门禁与借阅设备都支持扫码。两者共用同一账户，但使用条件和限制并不完全一样。
- 校园码依赖网络和手机电量，长时间在外建议仍随身带卡。
- 二维码有时效，过期后需要重新生成再扫。
- 截图保存的二维码可能失效，不要长期使用旧截图。
- 手机没电或丢失时，可凭有效证件到窗口说明情况。
- 校园码同样仅限本人使用，转借可能被记录并追责。

## 使用习惯与安全
- 不要把卡片借给他人进馆或过闸，转借可能触发账户风控。
- 卡片遗失后应尽快挂失，避免他人在门禁和借阅场景冒用。
- 在图书馆遗失卡片，可先向馆内服务台说明情况，再走挂失流程。
- 刷卡记录可用于核查进出时间，发现异常记录及时反馈。
- 图书馆的开放时间与通行规则以场馆公告为准。
