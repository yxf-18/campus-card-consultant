# 校园卡常见报错与处理

> 演示资料，不作为学校正式制度依据。

报错提示看起来五花八门，实质上大多可以归入四类：卡片本身、账户状态、终端与网络、身份权限。先归类再处理，能避免在错误的方向上反复尝试。

## 先做的基础排查
- 换一台终端重试，排除单台设备故障。
- 用校园码替代实体卡，判断是卡片问题还是账户问题。
- 查询余额和最近流水，确认账户状态是否正常。
- 确认卡片是否已激活、是否在有效期内。
- 回忆最近是否改过密码、挂失过或换过手机号。
- 手机系统时间明显偏差时，扫码失败也可能与此有关。
- 记录报错原文和发生时间，便于后续反馈。

## 卡片类报错
- 提示读卡失败、无效卡：多为卡片磨损、消磁或芯片接触不良。
- 卡片与手机、磁扣长期贴放，可能影响读卡稳定性。
- 卡面有明显裂痕或变形时，不建议继续反复尝试。
- 处理方式是按补办流程换卡，补办前先挂失避免被冒用。
- 补办前把卡面编号记下来，方便核对旧卡记录。

## 账户类报错
- 提示余额不足：充值后重试，注意确认是否已到账。
- 提示账户冻结：常见于挂失、异常交易或身份状态变化。
- 提示密码错误：核对账号和密码后可以直接重试；忘记密码请联系学校卡务中心重置。
- 提示账户不存在或未绑定：多为信息未同步，联系卡务窗口核实。
- 提示账户余额异常：先查流水，再按余额与流水不一致的思路排查。

## 终端与网络类报错
- 提示连接超时、网络异常：属于终端侧问题，可稍后重试。
- 提示系统维护：等待维护结束后再使用。
- 同一终端多人同时失败，基本可判断为设备或网络故障。
- 遇到此类报错不必反复刷卡，改用其他支付方式更稳妥。
- 终端显示的时钟明显不对时，交易时间也可能失真，留意留存凭证。

## 身份与权限类报错
- 提示无权限、不在有效范围：多见于门禁、图书馆、场馆场景。
- 原因可能是权限未开通、已过期或身份状态变更未同步。
- 这类问题卡务窗口通常无法直接修改，需由业务部门处理。
- 刚办完手续就失败属于常见情况，可等待同步后再试。
- 权限范围与生效规则以学校正式通知为准。

## 什么时候必须去窗口
自助方式能解决大部分常见报错，但涉及身份核验和账户变更的业务，通常必须本人到场。
- 需要重置密码而线上验证不通过时。
- 卡片明显损坏需要换卡时。
- 账户被冻结需要当面核实原因时。
- 姓名、证件信息发生变更需要更新时。
- 具体可办业务与所需材料以学校正式通知为准。

## 反馈时提供什么
- 卡面编号或学号，以及发生问题的时间。
- 报错提示的原文，尽量准确复述或拍照留存。
- 终端位置或编号，比描述某个食堂更有效。
- 已尝试过的处理方式，例如换终端、重新登录。
- 通过学校正式渠道提交，不向陌生人提供密码和验证码。
- 具体处理流程与时限以学校正式通知为准。
