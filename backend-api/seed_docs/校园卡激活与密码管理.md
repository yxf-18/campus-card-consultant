# 校园卡激活与密码管理

> 演示资料，不作为学校正式制度依据。

新领取的校园卡通常需要激活后才能消费。具体激活渠道以学校正式通知为准。

## 新卡激活
- 通过学校官方校园卡应用、服务窗口或自助终端完成激活。
- 激活时需核对姓名、学号和卡号，确认信息无误。
- 激活后建议先查询余额，并在支持的终端完成一次小额消费测试。
- 若提示“未激活”或“账户不存在”，请携带有效证件前往卡务中心处理。

## 密码修改
- 校园卡查询密码和消费密码可能分开管理，请以学校实际设置为准。
- 修改密码应通过学校官方渠道，不要使用来源不明的链接。
- 新密码不要与生日、学号、手机号后六位等容易猜测的信息相同。

## 忘记密码
- 使用学校官方提供的身份核验或重置流程。
- 无法自助重置时，携带有效身份证件到卡务中心办理。
- 任何工作人员都不会向你索要完整密码或短信验证码。
