# 校园卡余额不足与自动充值说明

> 演示资料，不作为学校正式制度依据。

余额不足是校园卡最常见的使用中断原因。它可能是真的没钱了，也可能是充值未到账、扣款在途或账户被限制。先判断属于哪一种，再决定是充值、等待还是申诉。

## 余额不足的常见表现
- 消费终端提示余额不足，交易被拒绝。
- 食堂、超市等场景刷卡失败，改用其他支付方式后正常。
- 自助设备提示账户可用余额低于本次消费金额。
- 校园码付款时提示扣款失败，但订单已经生成。

## 现场先做三件事
- 查询当前余额，确认与自己的预期差多少。
- 查看最近几条流水，确认是否有刚发生的扣款或退款。
- 若刚充值过，先等待一段时间再查，避免重复支付。
- 确认无误后再充值，不要在同一时间反复提交多笔订单。

## 自动充值是什么
- 自动充值是指在余额低于设定阈值时，由系统按预设金额自动从绑定账户扣款补足。
- 它解决的是忘记充值导致排队时刷不出钱的问题，不是无限制透支。
- 是否提供该功能、支持哪些扣款渠道，以学校正式通知为准。
- 开启前需要先完成实名绑定，并确认扣款账户状态正常。

## 自动充值没有触发的原因
- 余额尚未低于设定的触发阈值。
- 绑定的扣款账户余额不足、已过期或被限制交易。
- 单笔或单日自动充值次数达到上限。
- 卡片处于挂失、冻结或未激活状态，系统不允许入账。
- 系统正在维护或网络延迟，扣款与入账尚未完成。

## 扣款成功但余额没变
- 先查流水，确认是否已生成充值记录，只是余额显示未刷新。
- 退出应用后重新登录，或换一个渠道查询余额。
- 若扣款渠道有记录而校园卡无记录，保留订单号、时间和金额。
- 通过学校正式客服渠道提交核查，不要向他人提供支付密码或验证码。
- 核查期间避免重复充值，以免形成多笔待处理订单。

## 怎么判断该充多少
充值金额没有统一建议，按自己的消费频率估算更实际。一次充太多，卡丢失时损失也更大。
- 先看最近一段时间的日均消费，再决定充值额度。
- 余额长期偏高时，可适当减少单次充值金额。
- 大额充值前确认卡片状态正常，避免充进已挂失的账户。
- 卡片遗失后应先挂失，再处理余额问题。
- 是否支持退款或余额转移，以学校规则为准。

## 关闭与调整
- 自动充值可以按需关闭，关闭后需自行手动充值。
- 调整阈值和金额前，先估算自己的日常消费水平，避免频繁触发。
- 更换绑定账户后，建议先做一笔小额手动充值验证通道是否正常。
- 毕业、离校或长期不用卡时，建议关闭自动充值并核对余额。
- 使用自动充值后仍要偶尔查看余额，避免扣款失败而不自知。
- 换手机号或银行卡后及时更新绑定信息，否则自动充值会中断。
- 具体阈值、金额和到账时间均为示例性质，以学校正式通知为准。
