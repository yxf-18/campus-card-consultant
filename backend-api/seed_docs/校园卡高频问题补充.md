# 校园卡高频问题补充

> 演示资料，不作为学校正式制度依据。

## 校园卡可以借给同学使用吗？
不可以。校园卡仅限本人使用，出租、转借可能违反学校管理规定，也会增加账户风险。

## 校园卡余额可以提现吗？
校园卡余额通常只能在校内指定场景消费，是否支持退款或注销退余额以学校规则为准。

## 补办新卡后原卡还能用吗？
多数情况下补办后原卡会失效，具体以学校系统规则为准。补办前请确认原卡是否已挂失。

## 消费时提示余额不足怎么办？
先查询余额和最近流水，确认是否充值到账；如已扣款未到账，保留订单信息联系卡务中心。

## 校园卡被冻结怎么办？
冻结原因可能包括挂失、异常交易或身份状态变化。请通过学校正式渠道核实原因并按要求办理解冻。

## 如何保护校园卡账户安全？
设置不易猜测的密码，不转借卡片，不向他人提供验证码，发现异常交易及时挂失。
