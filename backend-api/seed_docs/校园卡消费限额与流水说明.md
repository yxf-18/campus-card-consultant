# 校园卡消费限额与流水说明

> 演示资料，不作为学校正式制度依据。

学校可能对校园卡设置单笔、单日或特定场景消费限额，具体数值以学校正式通知为准。

## 消费限额
- 限额可能按商户类型、消费场景或账户状态区分。
- 超过限额时终端会提示失败，可更换支付方式或分次消费。
- 限额调整通常需要学校审核，不能通过本咨询工具修改。

## 流水查询
- 可在校园卡应用、自助终端或服务窗口查询交易流水。
- 流水通常包含交易时间、商户、金额和交易状态。
- 充值记录与消费记录可能分开展示，请分别核对。

## 对账建议
- 每周至少核对一次流水，及时发现异常交易。
- 发现不明交易时，先挂失再提交核查，避免损失扩大。
- 不要将完整流水截图公开发布，注意遮挡卡号和身份信息。
